Check UAE Visa Status: GDRFA & ICP

Find the official portal for checking a UAE visa application, residence validity or Emirates ID application. Start with the authority that issued your file.

Choose the correct official portal

The UAE Government directs Dubai visa enquiries to GDRFA and enquiries for Abu Dhabi, Sharjah, Ajman, Umm Al Quwain, Ras Al Khaimah and Fujairah to ICP. Use the issuing authority shown on your application receipt.

How to check a visa application

  • Open the official authority page above.
  • Choose the enquiry that matches application status or file validity.
  • Enter the details requested on that official page, using your receipt or passport.
  • Review the result and retain the reference and date of your check.

The fields can differ between enquiry types. An application reference, visa file number and passport number serve different purposes; use the identifier the form requests.

Track an Emirates ID application

ICP directs applicants to its Smart Services application tracker. Its FAQ describes tracking with an application number beginning with 010. Use the reference on your own receipt or your account’s application list, and follow the current form instructions.

Application status and validity answer different questions

Application status helps you understand a submitted request. File validity concerns an existing immigration file or permit. A result from one enquiry should not be treated as confirmation of the other. Read the result against the exact transaction you submitted.

If you cannot find your request, compare the reference and issuing authority with your receipt. Ask the submitting party for the official application receipt, rather than repeatedly entering unrelated numbers.

If the result is unclear

Contact GDRFA for Dubai visa enquiries or ICP for enquiries handled by ICP. The UAE Government’s tracking page provides the current official contact details. For a QuickDocs-submitted application, contact us with the application reference so we can help identify the next step.

Status checks take place on the official government portal. This page does not collect passport details or retrieve a private application result.
